📚 JSON Test API - Static Version

This is a static version of the JSON Test API. All data is read-only.

📦 Available Resources

GET api/posts.json

Returns an array of blog posts.

GET api/comments.json

Returns an array of comments on posts.

GET api/albums.json

Returns an array of photo albums.

GET api/photos.json

Returns an array of photos.

GET api/todos.json

Returns an array of todo items.

GET api/users.json

Returns an array of users.

🚀 Usage Examples

fetch('https://ihsbramn.github.io/jsontestapi/api/posts.json')
  .then(response => response.json())
  .then(posts => console.log(posts));
